# AccountingSystem

نظام محاسبي مكتبي مبني باستخدام **C# وWindows Forms** ويعمل على **.NET Framework 4.8** مع قاعدة بيانات **Microsoft SQL Server**.

المشروع يحتوي على إدارة الحسابات، الفروع، الصناديق، المخازن، الموظفين، العملاء والموردين، المبيعات والمشتريات، القيود المحاسبية، التحويلات المخزنية، الصلاحيات، العملات والتقارير.

> المستودع حاليًا مخصص لتطوير النظام وحفظ تاريخه على GitHub.

## التقنيات المستخدمة

- C#
- Windows Forms
- .NET Framework 4.8
- Microsoft SQL Server / SQL Server Express
- Entity Framework 6
- RDLC / Microsoft ReportViewer
- NuGet
- Bunifu UI
- Guna UI2
- Krypton Toolkit

## قاعدة البيانات

الإعداد الافتراضي الحالي للنظام:

```text
SQL Server: .\SQLEXPRESS
Database:   AccountingSystemDB
```

الاتصال يستخدم Windows Integrated Security.

يوجد في جذر المشروع ملف:

```text
AccountingSystemDB.sql
```

لاستخدامه عند الحاجة لإنشاء قاعدة البيانات.

كما يوجد:

```text
RenameExistingDatabase.sql
```

لاستخدامه فقط عند ترقية نسخة قديمة كانت قاعدة بياناتها باسم مختلف.

## بيانات التهيئة الأولية Seed

عند تشغيل النظام على قاعدة بيانات فارغة، يقوم `DatabaseSeeder` بإنشاء البيانات الأساسية اللازمة لبدء الاستخدام، ومن أهمها:

- الريال اليمني `YER` كعملة رئيسية.
- مجموعات الحسابات الأساسية.
- شجرة حسابات أولية.
- الفرع الرئيسي.
- المخزن الرئيسي.
- الصندوق الرئيسي.
- نوع موظف لمدير النظام.
- مستخدم مدير النظام.
- الصلاحيات الأساسية.
- وحدة قياس افتراضية.

اسم مستخدم مدير النظام الافتراضي:

```text
admin
```

كلمة المرور **لا تكون ثابتة داخل المستودع**؛ يتم توليد كلمة مرور مؤقتة عند أول Seed، وتظهر في نافذة مخصصة تسمح بنسخ اسم المستخدم وكلمة المرور.

> احفظ بيانات الدخول عند ظهورها لأول مرة، لأن كلمة المرور المؤقتة لا يتم عرضها مرة أخرى تلقائيًا.

## تشغيل المشروع

راجع دليل الإعداد الكامل:

[docs/SETUP.md](docs/SETUP.md)

باختصار:

1. ثبّت Visual Studio مع دعم تطوير تطبيقات سطح المكتب لـ .NET.
2. ثبّت SQL Server Express أو SQL Server.
3. تأكد أن instance الافتراضي المطلوب هو `.\SQLEXPRESS` أو عدّل `App.config`.
4. استعد حزم NuGet.
5. جهّز قاعدة `AccountingSystemDB`.
6. افتح:
   ```text
   AccountingSystem.sln
   ```
7. نفّذ:
   ```text
   Build > Rebuild Solution
   ```
8. شغّل المشروع.

المشروع يستخدم ملفات `RDLC` وMicrosoft ReportViewer لعرض عدد من التقارير، وتوجد ملفات التقارير تحت:


## ملاحظات مهمة للمطورين

### مجلد packages

لا يلزم رفع مجلد `packages` إلى GitHub. الحزم يتم استعادتها باستخدام NuGet من `packages.config`.

### ملفات البناء

لا يتم رفع المجلدات المؤقتة مثل:

```text
.vs/
bin/
obj/
```

وذلك من خلال `.gitignore`.

### مرجع Bunifu القديم

يوجد في المشروع مرجع قديم إلى:

```text
Bunifu.UI.WinForms.1.5.3.dll
```

بمسار محلي على جهاز المطور. في المقابل توجد نسخة حديثة من Bunifu ضمن NuGet. إذا ظهر تحذير بأن المرجع القديم غير موجود، فيجب إزالة الاعتماد المحلي أو استبداله بطريقة لا تعتمد على مسار Desktop خاص بجهاز واحد.

### الأمان

لا ترفع إلى GitHub:

- كلمات مرور قواعد البيانات.
- API Keys.
- Tokens.
- ملفات تحتوي بيانات دخول فعلية.
- نسخ قواعد بيانات حقيقية تحتوي بيانات مستخدمين أو عملاء.
